# Ô chat NMB Hub nhận ảnh dán Ctrl+V và kéo-thả file.

**Câu hỏi dẫn tới:** Không gửi được ảnh chụp màn hình.

Ảnh chụp Win+Shift+S/PrtSc nằm trong bộ nhớ tạm: Ctrl+V vào ô chat hoặc khung đen là đính kèm (tên anh-chup-<giờ máy>.png), kéo-thả file vào cuộc chat cũng được; file vào data/inbox, đường dẫn chèn vào ô chat.
