# Đăng nhập Claude Code trong NMB Hub: /login và mã đăng nhập phải gửi nguyên văn.

**Câu hỏi dẫn tới:** Không đăng nhập được Claude trên máy nhân sự

Bộ ghép lệnh chèn mã #xxxxx và phần 'Gợi ý từ NMB Hub' vào mọi tin nên /login và mã dán vào bị hỏng. Đã sửa: lệnh bắt đầu bằng '/', chuỗi dài không dấu cách, hoặc lúc màn hình đang hỏi login method / paste code thì gửi nguyên văn. Agent & Addon có nút 'Đăng nhập' cạnh Claude Code (mở cuộc chat, tự gõ /login). Cách khác: mở PowerShell trên máy đó, gõ claude rồi /login; NMB Hub dùng chung đăng nhập vì cùng tài khoản Windows.
