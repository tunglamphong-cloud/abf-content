# GitHub → Vercel

## Repository mới

Mỗi landing page là một repo riêng, mặc định private:

```bash
gh repo create OWNER/PROJECT --private --source=. --remote=github --push
gh repo view OWNER/PROJECT --json name,isPrivate,defaultBranchRef,url
gh api repos/OWNER/PROJECT/commits/main
```

Không push `.env`, token, credential, PDF/ảnh nguồn chưa tối ưu hoặc file chứa dữ liệu khách hàng. Dùng `.env.example` với giá trị rỗng và hướng dẫn tên biến.

## Phân biệt trạng thái

| Trạng thái | Ý nghĩa |
|---|---|
| GitHub pushed | Source đã nằm trong repo |
| Vercel project created | Project tồn tại |
| Git linked | Push mới tự tạo deployment |
| Deployment ready | Build/runtime chạy thành công |
| Production live | Domain production trả HTTP 200 và hiển thị đúng app |

Không gộp bốn trạng thái đầu thành “đã deploy”.

## Vercel

Khi user yêu cầu deploy, ưu tiên connector `create_git_project` với repo GitHub, provider GitHub, project name duy nhất, team đúng và deploy enabled. Trước khi gọi tool cần đọc schema đầy đủ. Nếu lỗi link Git:

1. Không gọi lại tạo project trùng tên.
2. Kiểm tra team, GitHub App permission và project settings.
3. Kiểm tra deployment list/logs.
4. Báo project có thể đã tạo nhưng cần link thủ công nếu connector thiếu quyền.

## Build settings

- Next.js: dùng preset Next.js, không thêm `vercel.json` trừ khi cần rewrite/header.
- Vite + Express: kiểm tra Node function adapter; không giả định server listener lâu dài trên serverless.
- Build command và output phải khớp `package.json`.
- Chạy build local trước khi deploy.

## Environment Variables

Trong Vercel Project Settings → Environment Variables:

```text
TELEGRAM_BOT_TOKEN=<secret>
TELEGRAM_CHAT_ID=<chat id>
NEXT_PUBLIC_SITE_URL=https://domain.example
```

Thêm đúng Production/Preview/Development. Sau khi đổi env, redeploy. Không commit giá trị thật vào `.env.example`, README hoặc frontend.

## Production verification

```bash
curl -I https://domain.example
curl -L -s https://domain.example | grep -E "<title>|Project Name"
```

Kiểm tra domain canonical, www redirect, title/metadata, asset load, form endpoint, privacy route và mobile preview. Báo rõ URL GitHub, Vercel, preview, production và domain custom.

## No deployment by default

Chỉ tạo repo khi user yêu cầu “tạo repo/push GitHub”. Chỉ deploy khi user yêu cầu “deploy/xuất bản/kết nối Vercel”. Nếu user chỉ yêu cầu xây, dừng ở code đã test và checkpoint/preview.
