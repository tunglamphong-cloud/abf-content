# Google Flow – bài học lái tự động 19/10/2026

(1) KHÔNG bao giờ bấm Enter trong ô lệnh: bảng cài đặt kẹt mở làm @ không bật danh sách, Enter tạo ~10 clip rác (~110 credit). Dùng khung/gen4.sh: Xoá câu lệnh → đặt thời lượng + kiểm tra → gõ @ + 6 ký tự lọc → JS .click() button[role=option] → kiểm chip, không dính thành phần video → dán prompt → kiểm → Bắt đầu tạo. Chữ→video không ảnh: khung/gentxt.sh. (2) Flow đổi tên miền flow.google.com, Chrome chặn tải nhiều tệp (anh đã cấp quyền 19/10); dự phòng khung/dltab.sh mở mỗi clip ở tab mới /edit/<media_id> tải 1080p. (3) Tab Flow hay bị đóng → khung/motab.sh mở lại và thay mã tab trong mọi script. (4) Prompt cảnh tắm/ngâm mình bị Flow từ chối → mô tả kín đáo (áo choàng, ngâm chân). (5) Lọc 
 khi đọc danh sách do Python sinh; đường dẫn trong code Python dùng '/'.
